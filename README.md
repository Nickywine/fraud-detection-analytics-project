# Fraud Detection Analytics Project

## Business Problem
Design an end-to-end fraud detection analysis system 
to identify suspicious transactions, high-risk customers, 
and financial crime patterns across a simulated dataset.

## Dataset
- 50 transactions across 15 customers and 10 merchants
- Includes confirmed fraud, structuring, mule activity, 
  PEP transactions, and blacklisted merchant exposure

## Tools Used
- SQL (MySQL) — pattern analysis and fraud detection queries
- Python (Pandas, Seaborn) — EDA and statistical analysis
- Power BI — KPI dashboards and visualization
- Lucidchart — BPMN process flows
- Documentation — BRD, UAT test cases

## Key Findings
- Crypto and remittance merchants account for 100% of fraud
- 3 customers showed structuring patterns below $50K threshold
- PEP customers generated highest transaction volumes
- Low-risk rated customers transacted with blacklisted merchants
